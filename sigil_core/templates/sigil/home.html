What Sigil is

Three things JSON cannot do, by construction.

01 / Dependent types

Dependent types in a communication language.

Express "a vector of exactly n elements" or "a positive integer" in the type signature of a message. Π(n:Nat) Vec(n), Σ(x:A) B(x), {x:Int | x > 0} — all shipped, all tested. 

(guarantee :type
  Π(n:Nat) (Completion n))

02 / Probability

Probability as syntax, not metadata.

P(market_crash | recession) = 0.73 is a parseable expression, not a string in a JSON field. Named distributions, conditional probability, Bayesian update operators — all in the grammar. 

(probability
  :success ~ Beta(94, 6))

03 / Round-trip

Round-trip serialization.

Parse → AST → serialize → parse again. Deterministic. Content-hashable. Two agents comparing the same message produce the same hash. 

>>> parse(serialize(parse(src)))
<Message sha256:7d4a…b2c1>

The upgrade

The same agent message, twice. Read both columns and you have read the brief.

What JSON gives you 4 fields · no semantics

{
  "type": "negotiate",
  "skill": "translation",
  "confidence": 0.9,
  "price": 450
}
  • no type for confidence — is it probability, certainty, or a vibe?
  • no constraint on price — currency, scale, jurisdiction unknown
  • no formal arbiter when two agents disagree on what a field means
  • no round-trip guarantee — re-serialize and the key order drifts

What Sigil gives you parses · type-checks · round-trips

(offer :type Negotiate
  (service :skill "translation"
           :quality ≥ 0.94
           :price 450 $AETH)
  (probability :success ~ Beta(94, 6)))
  • type Negotiate chosen from the closed set of 9 message types
  • dependent constraint quality ≥ 0.94 — the parser enforces it
  • probability is a first-class expression: Beta(94, 6) is a distribution, not a string
  • round-trip: parse → AST → serialize → identical content hash

Producers and consumers

Who writes Sigil. Who reads it. How to embed it.

Who makes Sigil

The spec is the source of truth. The package sigil-core is the canonical reference implementation: lexer, parser, serializer, builder, 31 AST node classes, 298 tests. Pure Python, zero external dependencies beyond the standard library.

Language changes go through the SIP process — Sigil Improvement Proposals. The community reviews; v1.0.0 lands when the grammar is locked.

Who reads Sigil

Aetheria — the on-chain civilization — uses Sigil for every agent-to-agent message. Largest production consumer. (Same engine; different brand. The civilization is not the language.)

Aether — the household AI cluster — coordinates devices in Sigil. cake-core parses Sigil to dispatch local inference. GreyAgent reads Sigil to route cross-module tasks.

How to embed Sigil

Sigil is a message format, not a framework. Any agent runtime that passes messages can use Sigil-encoded payloads. The grammar before the protocol; the parser before the framework.

First-class integration guides for LangGraph, AutoGen, CrewAI, MCP, and A2A land in /docs as they ship. Sigil is brand-neutral by design — it is the language Aetheria speaks, not an Aetheria sub-brand.
